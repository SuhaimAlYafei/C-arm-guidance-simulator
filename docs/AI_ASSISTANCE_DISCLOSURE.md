# AI Assistance Disclosure

This file documents AI-assisted software development in this repository for transparency and reproducibility.

## Scope

AI tools were used as a software-development resource for selected implementation, debugging, architecture, test design, and documentation tasks. AI-generated suggestions were reviewed, edited, selected, and integrated by the student developer and collaborators responsible for the project.

Examples of AI-assisted development in the current research branch include:

- operating-room scene architecture suggestions
- collision-envelope and scene-space path-checking code assistance
- interactive OR layout editor code assistance
- dynamic respiratory-envelope and adaptive replanning code assistance
- metal-in-beam and relative radiation/scatter proxy code assistance
- unit-test and CI workflow assistance

## Important competition boundary

This disclosure is **not** an ISEF research plan, abstract, poster, presentation script, or citation list. Those competition materials must be prepared by the student in accordance with the applicable Society for Science / Regeneron ISEF rules.

AI-produced text or code must not be represented as independently authored student work when disclosure is required. Any externally sourced algorithms, datasets, models, publications, or code must be cited separately using the original source.

## Verification responsibility

Every AI-assisted code contribution remains subject to:

- student review and understanding
- source-code inspection
- automated tests where practical
- controlled simulator trials
- independent validation before scientific claims are made

The simulator remains research software. AI assistance does not establish clinical accuracy, medical-device safety, collision-safety certification, or radiation-dose accuracy.
