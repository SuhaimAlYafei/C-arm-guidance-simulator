# Simulated Planner Validation

This directory contains a reproducible, software-only benchmark for the C-arm positioning planner.

## Purpose

The benchmark stress-tests the deterministic planner across randomized starting poses, anatomical target coordinates, projection types, oblique angles, and waypoint counts. It measures internal simulator consistency and planning performance.

It **does not** measure physical C-arm accuracy, clinical performance, radiation reduction, or patient outcomes.

## Run

From the repository root:

```bash
python evaluation/simulated_validation.py --trials 1000 --seed 23112
```

For a larger run:

```bash
python evaluation/simulated_validation.py --trials 10000 --seed 23112
```

The fixed seed makes runs reproducible.

## Outputs

Results are written to `results/simulated_validation/`:

- `trials.csv`: one row per simulated planning trial
- `summary.json`: aggregate metrics and confidence bins

Metrics include:

- internal target-position residual (mm)
- requested projection angular residual (degrees)
- planning runtime
- linear and angular pose change
- path endpoint integrity
- waypoint progress monotonicity
- planner confidence
- planner uncertainty (`100% - confidence`)
- confidence/error correlation
- confidence/software-success correlation
- confidence-binned software success rates

## Software success criterion

A trial is counted as a software success when all of the following hold:

1. internal target-position residual <= 1.0 mm;
2. requested orbital-angle residual <= 0.1 degrees;
3. the generated path starts and ends exactly at the requested poses; and
4. waypoint progress is monotonic.

These thresholds are **simulation engineering criteria**, not demonstrated clinical tolerances.

## Interpretation

The confidence score is currently a deterministic engineering score based on target reachability, mechanical feasibility, path smoothness, and conservative registration certainty. The calibration table generated by this benchmark is exploratory: a confidence value must not be presented as a calibrated probability of clinical success unless later validation supports that interpretation.

When hardware is available, this same evaluation structure should be extended with independently measured physical position error, angular error, repeatability, execution time, collision/clearance outcomes, and a manual or preset-positioning baseline.
