Privacy Notice

C-Arm Guidance Simulator V3 | Research and educational software
This simulator is not a medical device and must not be used for patient care.

Information handled by the simulator

The application may process simulator selections, locally stored registration data, planner state, browser microphone input when voice search is activated, and questions submitted to Gemini Guidance.

Local browser data

Patient-landmark registration and some simulator settings may be stored in browser storage so they can persist between sessions. Clearing site data removes those local values.

Voice input

Voice search uses the browser speech-recognition capability when available. Microphone access begins only after the user activates voice search and grants browser permission. Speech handling may depend on the browser vendor's recognition service.

AI requests

Questions submitted through Gemini Guidance are sent through the configured Firebase AI integration so the assistant can respond using simulator context. Do not enter patient-identifying, confidential, or regulated clinical information.

Infrastructure

The public simulator uses Firebase Hosting and related application-protection services. The planning service is hosted separately. Service providers may process technical request data according to their own policies.

Intended use

This project is intended for research, engineering development, demonstrations, and education. It is not designed to collect real patient data.
